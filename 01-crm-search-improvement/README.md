CRM Search Improvement

1. Case Overview

Project Type: Simulated Business Analysis Case Study

Domain: Customer Relationship Management (CRM)

Status: In Progress

2. Case Objective

The objective of this case study is to investigate customer search problems in a CRM system, understand stakeholder needs, and identify business requirements for improving the search experience.

3. Analysis Scope

- Understand the reported search problems.
- Identify relevant stakeholders.
- Distinguish available evidence from assumptions.
- Develop questions to investigate the problem.
- Document validated requirements and potential improvement options.

4. Current Status

The case study is in the initial investigation stage. Further analysis is required before confirming root causes or recommending a solution.

5. Deliverables

- Problem Analysis
- Stakeholder Analysis
- Elicitation Questions
- Requirements Document
- Solution Evaluation

This is a simulated learning project, not a professional client engagement.
